# RateShield — Distributed API Rate Limiting Service
A high-performance, distributed rate-limiting service built with Go and Redis to protect APIs from excessive traffic using configurable rate-limiting algorithms.

RateShield is a production-oriented distributed API rate-limiting
service being built with Go and Redis.

The project is being developed incrementally to explore:

- Rate-limiting algorithms
- Go concurrency
- Redis-based distributed state
- Atomic operations with Redis Lua
- Horizontal scaling
- Fault tolerance
- Observability
- Performance testing
